## 🎯 Try These Features

1. **Submit an Issue**
   - Login as resident
   - Click "Submit Report"
   - Fill in form with issue details
   - Optional: Upload photo
   - Submit and see it in "Track Reports"

2. **Update Issue Status**
   - Login as official
   - Click "View Assigned Issues"
   - Click "Manage" on any issue
   - Change status from "Open" to "In Progress"
   - Official notes (optional)
   - Click "Update Issue"

3. **Create New User**
   - Login as admin
   - Scroll to "Add New User"
   - Fill in all required fields
   - Click "Create User"
   - New user appears in the list

4. **Search Legislation**
   - Click "View Legislation"
   - Type keyword in search (e.g., "Waste")
   - Filter by category
   - Click "Filter"

## ❓ FAQ

**Q: What's the password for all test accounts?**  
A: `password` (case-sensitive)

**Q: Can residents see other residents' issues?**  
A: No - residents only see their own issues. Officials/admins see all.

**Q: Do residents need to be verified?**  
A: Yes - pending residents can't access some features. Admin must verify them.

**Q: Can I create new accounts?**  
A: Yes - residents can self-register, admins can create officials.

**Q: Where's the data stored?**  
A: MySQL database named `barangay_system`

**Q: How do I reset the system?**  
A: Run: `mysql -u root < db_init.sql`
